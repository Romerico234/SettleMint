# SettleMint

SettleMint is a wallet-based group expense and settlement application. It combines shared-expense tracking, settlement-cycle workflows, and blockchain-backed settlement proof in a single full-stack project.

The repository is organized into five main parts:

- `settlemint-ui`: frontend application
- `settlemint-service`: backend API and persistence layer
- `settlemint-chain`: shared blockchain network definitions
- `settlemint-contracts`: settlement contract and deployment tooling
- `scripts`: development helper scripts

For the full technical walkthrough of how the system works, see [docs/docs.md](./docs/docs.md).
